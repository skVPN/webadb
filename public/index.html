常见问题

需要安装什么软件吗？
完全不需要。只要有 Chrome 或 Edge 浏览器，打开网页就能用。手机端也不需要安装任何 APP。
支持 Wi-Fi 连接吗？
目前仅支持 USB 有线连接。WebUSB API 需要物理 USB 连接才能工作。
数据安全吗？会上传到服务器吗？
所有数据（截屏、命令、日历）100% 在你的浏览器本地处理，不会上传到任何服务器。项目完全开源（MIT 协议），代码可审计。
收费吗？
完全免费。AI 营销日历功能需要你自己配置 LLM API Key（如 DeepSeek），API 费用由对应平台收取。
需要 ROOT 吗？
不需要。只需开启 USB 调试模式即可，不需要 ROOT 或解锁 Bootloader。

准备好了吗？

插上数据线，打开 Chrome，三秒开始控制你的 Android 设备。
